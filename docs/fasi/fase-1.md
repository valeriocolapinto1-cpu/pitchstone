# Fase 1: dati e sincronizzazione

Stato: da iniziare

## Obiettivo

Modello dati in SwiftData, outbox, pull e push con Supabase, versioni dei nodi, cestino.

## Criteri di completamento

- [ ] Un nodo creato su un dispositivo compare sull'altro.
- [ ] Modifiche offline vengono sincronizzate al ritorno della connessione.
- [ ] Il cestino conserva per 30 giorni.

## Test

- [ ] Test unitari sul sync.
- [ ] Test di conflitto con due versioni.
